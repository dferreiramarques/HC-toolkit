HR MONCO — instruções depois de extrair este zip
==================================================

O Windows bloqueia ficheiros .js recém-transferidos da internet (proteção
do Defender/SmartScreen contra scripts). Por isso os 3 ficheiros .js do
projeto foram renomeados para .txt dentro deste zip:

  server.js.txt
  public/app.js.txt
  public/sw.js.txt

PASSO ÚNICO — restaurar tudo de uma vez:

1. Extrai o zip normalmente (todos os ficheiros devem sair, incluindo os .txt).
2. Abre o PowerShell NA PASTA do projeto extraído (Shift + botão direito
   dentro da pasta → "Abrir janela do PowerShell aqui", ou "Abrir no
   Terminal").
3. Cola e corre este comando:

   Get-ChildItem -Recurse -Filter *.js.txt | Rename-Item -NewName { $_.Name -replace '\.txt$','' }

Isto renomeia os 3 ficheiros de volta para .js automaticamente (server.js,
app.js, sw.js). Depois disso, segue o normal:

   npm install
   npm start

Se preferires, também podes simplesmente fazer upload da pasta (com os
nomes .js já corretos) diretamente para o GitHub e deixar o Railway tratar
do deploy — nesse caso nem precisas de correr nada localmente.
